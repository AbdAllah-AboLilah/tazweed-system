Collection: users
────────────────────────────────────────
Document ID: لازم يكون نفس الـ UID بتاع الحساب في Authentication
{
  "name": "اسم الشخص الحقيقي",
  "role": "admin",
  "warehouseAccess": null
}

قيم role الممكنة: admin | branch_manager | supervisor | warehouse_keeper | user
قيم warehouseAccess (لأمين المخزن فقط): "branch" | "main" | "both"

حقل اختياري جديد: canSendRemotePrint: true — لو موجود ومساوي true، الشخص
ده يقدر يبعت طلب طباعة (ملصق أو ورقة تزويد) لمكان تاني (فرع/رئيسي) غير
مكانه، حتى لو مش من أصحاب الصلاحية الكاملة. لتفعيلها لشخص معين، ضيف الحقل
ده يدويًا في مستند users/{uid} بتاعه في Firestore Console.

────────────────────────────────────────
Collection: printJobs (يُنشأ تلقائيًا، لا تحتاج تضيفه يدويًا)
────────────────────────────────────────
كل طلب طباعة لجهاز تاني بيضيف مستند هنا تلقائيًا، وبيتحول لـ
status: "printed" أول ما الجهاز المستقبِل يطبعه.

الطلب بيتبعت لـ **جهاز محدد** (targetDeviceId) مش لمكان (فرع/رئيسي) —
لأن الطابعات كلها في مكتب الكاشير في الفرع. والصفحة بتتبعت **جاهزة
بالكامل** في حقل html (بما فيها صورة الـQR)، عشان اللي بيتطبع هناك يبقى
بالظبط اللي الباعت شافه في المعاينة عنده.
{
  "type": "label",                    // label | restock
  "targetDeviceId": "dev-a1b2c3d4...", // معرّف الجهاز المستقبِل
  "html": "<!doctype html>...",       // الصفحة كاملة جاهزة للطباعة
  "sizeOptions": { "pageWidthMm": 38, "pageHeightMm": 25, "halves": 2 },
  "status": "pending",                // pending | printed | failed
  "requestedByUid": "...",
  "requestedByName": "اسم الشخص",
  "createdAt": <server timestamp>,
  "printedByUid": "...",              // بيتضافوا لما يتطبع
  "printedByName": "اسم الشخص",
  "printedAt": <server timestamp>
}

Collection: printStations (يُنشأ تلقائيًا، لا تحتاج تضيفه يدويًا)

كل جهاز عليه QZ Tray وطابعة محفوظة بيسجّل نفسه هنا وبيحدّث lastSeen كل
45 ثانية. ده اللي بيخلي اللي بيطبع يشوف الأجهزة المتصلة **دلوقتي** بالاسم.
الجهاز بيتعتبر "متصل" لو آخر نبضة ليه أقل من دقيقتين.
